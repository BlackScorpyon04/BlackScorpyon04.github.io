I got into plugin development because it sounded fun — and it was. I've been self-taught from the start, picking it up on and off over the past 7 years, building things that interested me and learning as I went.

My flagship plugin, Simple Player Tracker, has crossed 38,000 downloads. It started as a simple idea and has been updated through multiple major API versions — most recently migrated to Paper's Adventure API with full Folia support for regional threading.

I'm comfortable across the full plugin lifecycle: architecture, event-driven design, GUI inventory UIs, config systems, scheduler abstraction for Folia compatibility, and JitPack distribution. I keep up with the ecosystem as it moves — Paper switched from 1.x to year-based versioning in 2026 and I had updates out quickly.

Open to commissions — new plugins, updates to existing ones, Folia migrations, or custom features for your server.
